# อ่านสิทธิ์ไอเทมจาก PostgreSQL (ยังไม่ได้เชื่อมเข้ากับเกม)

ตัวอ่านนี้รับเฉพาะที่นั่งซึ่งเซิร์ฟเวอร์ยืนยันและจองแล้ว 2 หรือ 4 ที่นั่ง ใช้ PostgreSQL อ่านสิทธิ์โล่และ ×2 ด้วยเวลาฐานข้อมูลค่าเดียวต่อคำสั่ง ช่วงสิทธิ์คือ [เริ่ม, หมดอายุ) ผู้ไม่มีแถวที่ active จะได้ false/false ครบทุกที่นั่ง ถ้าฐานอ่านไม่ได้หรือผลขาด จะปฏิเสธแทนการเดา สิทธิ์ VIP ไม่ใช่สิทธิ์ไอเทม

ต้องใช้ session ของ login อ่านอย่างเดียวที่แยกจาก gameplay และผ่าน RLS ไม่ได้สร้าง login จริงในต้นแบบนี้ เซิร์ฟเวอร์ต้องตรวจซ้ำว่าการจองยังเป็นของ UID เดิมก่อน INSERT และใช้ snapshot ที่บันทึกไว้ตอน resume ไม่อ่านสิทธิ์ใหม่เพื่อเติมโล่ ตัวอ่านให้ผล ณ เวลาที่อ่าน ไม่ได้ล็อกการเพิกถอนพร้อมการสร้างห้อง

```sh
node --test qa/pg-item-entitlements.test.cjs
python3 qa/item-reader/run.py /absolute/pg17/bin /absolute/checkout/backend/supabase
```

SQL เป็นแบบจำลองในฐานชั่วคราว ไม่ใช่ migration สำหรับบริการจริง ยังไม่กำหนดผู้อนุญาตให้ grant/revoke, การต่ออายุ, การหมดสิทธิ์กลางเกม, หรือการชำระเงินจริง
