ตัวรันตรวจ Git blob ID ของอินพุตตาม source-blobs.json สำหรับ fenced-dialog.cjs ไฟล์รายการระบุ blob ต้นฉบับ ส่วน run.py ตรวจ blob ของ fixture ที่ปรับสำหรับชุดรวมในสาขานี้ จากนั้นสร้าง baseline และตัวทดลองในไดเรกทอรีชั่วคราว ตรวจ SHA-256 ของ public/index.html ใน baseline แล้วจึงเรียก joined.cjs โดยไม่ใช้ pg หรือเปิด listener

- เริ่มจาก callback การคลิกปุ่มทอยเดิมใน v12 ผ่าน EventTarget จำลอง ส่ง roll เข้า handle จริงที่ตัดจาก secure-server จากนั้นผ่านกติกา guard และ commitFencedTurn ของตัวทดลองจนถึงพารามิเตอร์ UPDATE ห้อง / INSERT คะแนน / INSERT ใบรับตา เมื่อไดรเวอร์จำลองตอบ COMMIT สำเร็จจึงตรวจข้อความในกล่องชนะเดิม
- ใช้สองห้องในข้อมูลชุดเดียว Free 4 ที่นั่งชนะ +10 และ VIP 2 ที่นั่งชนะ +20 ก่อนปิดรอบกรุงเทพฯ หนึ่งวินาที ผู้ชนะเริ่มด้วยคะแนนสะสม 55 จึงตรวจแยกยอดรางวัลจากยอดรวม นำ bindings ของห้อง ใบรับ และรายการคะแนนชุดเดียวกันมาประกอบเป็นแถวสำหรับ projectTerminalWin และการอ่านทั้งสองระบบ เวลา created_at เป็นค่าจำลองของ fixture
- หลังปิดรอบหนึ่งวินาที เรียก previous leaderboard handler ในหน่วยความจำ ตรวจหน้าต่าง Free 7 วัน / VIP 1 วันและ provisional: true ตัวอ่านใช้ SQL และ bindings ของ game-store จริง ส่วนการจัดกลุ่มและรวมคะแนนทำใน JavaScript ตรวจ 401 เมื่อไม่รู้จักผู้ใช้และ 403 เมื่อผู้เล่น Free ขอ VIP
- ตัวอ่านยอดห้องใช้พูลจำลองเฉพาะ Admin ตรวจคำสั่งเลือกบทบาทและการผูก UID ที่ยืนยันแล้ว ผู้เล่น Free/VIP อ้าง admin เองไม่ผ่าน ผู้ตรวจสอบที่แยกต่างหากได้ยอด finished อย่างละหนึ่ง ตรวจทุก state packet และผลอ่านที่ส่งออกว่าไม่มี UID ผู้เล่นหรือข้อมูลไอเทมส่วนตัว

ชุดนี้ใช้เฉพาะส่วน callback ของหน้าเกมและ handler ในหน่วยความจำ ไม่มีการสมัคร ซื้อไอเทม ตรวจ token จริง จัดคิวผู้เล่น เปิด HTTP/WebSocket หรือทดสอบ Chromium การตอบ COMMIT การตรวจบทบาท/RLS และการประมวลผล SQL ใช้ fixture ทั้งหมด การฉายรางวัลจากใบรับของห้องจบไม่ทำให้มีเส้นทางกลับเข้าห้องหลัง restart การรับรอง P1–P4 แบบครบวงจรและการทดสอบ Free4 พร้อมกันหลาย session ยังต้องมีหลักฐานแยก

## ตรวจ SQL ด้วย PostgreSQL 17 แบบ single-user (ตัวเลือกเสริม)

```sh
python3 "$ITEM/qa/cross-track-lab/run.py" --offline --postgres-bin /absolute/path/to/pg17/bin "$ITEM" "$LEADER" "$ADMIN"
```

ต้องมี PostgreSQL 17 และ initdb อยู่แล้ว ไม่เปิด socket, TCP หรือเครื่องใหม่ ตัวรันใช้ต้นทางที่ตรวจ blob แล้วและ schema เพิ่มอีก 6 ไฟล์ที่ pin ไว้ สร้างฐานชั่วคราวจากศูนย์ ตรวจ RLS ภายใต้ role เกมและ role อ่านยอดห้อง ใช้ค่าจากคำสั่งเขียนห้อง คะแนน และ receipt สองรายการเดิมกับ SQL ตรงจากโค้ด แล้วตรวจ Free +10, VIP +20, ความสอดคล้องของ receipt, ยอดห้องแยกโหมด, ไม่มีสิทธิ์ และสิทธิ์ถูกต้องแต่ไม่มีห้อง ค่าประทับเวลาใกล้ขอบรอบเป็นข้อมูลจำลองในฐานชั่วคราวเท่านั้น ไม่ใช่การเปลี่ยนกติกาเวลา เทสต์ rollback และลบฐานชั่วคราวหลังจบ ไม่ทดสอบ Node pg จริง, หลาย session, pooler, Google OAuth หรือ Chromium
