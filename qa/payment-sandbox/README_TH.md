# ทดสอบชำระเงินแบบจำลองในเครื่องเท่านั้น

รัน `node --test qa/payment-sandbox/local-settlement.test.cjs` ด้วย Node.js โดยไม่ติดตั้ง dependency เพิ่ม

ไม่มี HTTP endpoint, provider SDK, credentials, การเชื่อมฐานข้อมูล หรือการเปิดสิทธิ์จริง รหัสคำสั่งซื้อ ผู้เล่น การจ่ายเงิน และสินค้าใช้ prefix สำหรับห้องทดสอบ; ค่าเงินเป็น test vector ไม่ใช่ราคาที่อนุมัติ คีย์ HMAC ถูกสุ่มในหน่วยความจำต่อ fixture และไม่ถูกบันทึก

ต้นแบบตรวจลายเซ็นของ raw bytes แล้วอ่านสถานะจากผู้ให้บริการจำลองแยกจาก event จับคู่ข้อมูลนั้นกับคำสั่งซื้อของเซิร์ฟเวอร์ (order, payment ref, UID, สินค้า, จำนวนเงินหน่วยย่อยและสกุลเงิน) และไม่รับข้อมูลสิทธิ์จาก event บันทึก event ID กับผลชำระครั้งเดียวในหน่วยความจำ การคืนเงินเต็มจำนวนที่ตรวจสอบได้ยกเลิกเฉพาะเครื่องหมายสิทธิ์จำลองและการ replay เก่าไม่คืนสิทธิ์; การคืนเงินไม่เต็มจำนวนหรือสถานะไม่แน่ชัดไม่มีการเปลี่ยนแปลงอัตโนมัติ

ยังไม่ได้พิสูจน์ provider จริง, การจัดเก็บแบบทนต่อการรีสตาร์ต, การชนพร้อมกันหลาย process หรือธุรกรรมฐานข้อมูล สิ่งที่ต้องยืนยันก่อนพัฒนา integration จริง: ผู้ให้บริการและรูปแบบลายเซ็นที่อนุมัติ, secret rotation, online reconciliation, schema/role แยก, unique event/payment references และธุรกรรม atomic order/สิทธิ์/ประวัติการตรวจสอบ รวมถึงนโยบายคืนเงิน ห้ามย้าย signer ของ fixture ไป runtime
